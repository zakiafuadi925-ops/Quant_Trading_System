### Tahap 1: Standarisasi Data & Labeling (The Foundation)
Kesalahan umum adalah membiarkan model menebak harga mentah. Lebih baik ajarkan model menebak **Arah (Trend)**.

* **Data Cleaning:** Buat satu script khusus `clean_data.py` untuk menggabungkan CSV, menangani `_x/_y`, dan memastikan tidak ada nilai `NaN`.
* **Target Labeling:** Jangan gunakan harga besok sebagai target. Gunakan log return atau arah:
    * `1` jika harga besok naik > 0.5%.
    * `0` jika harga besok turun/stagnan.
* **Feature Selection:** Pilih maksimal 10-12 fitur terkuat (gabungan Teknikal + Astronacci) agar RAM tidak sesak.

### Tahap 2: Arsitektur "Hybrid" Model
Jangan hanya gunakan LSTM standar. Karena Anda memiliki data siklus (Astronacci), model perlu memahami konteks waktu lebih baik.

* **Scaling per Eksperimen:** Simpan file scaler untuk setiap versi model menggunakan `joblib`.
* **Model Architecture:** Gunakan **Bidirectional LSTM** atau tambahkan **Dropout Layer** untuk mencegah *overfitting* (kondisi di mana model hafal data masa lalu tapi gagal di data masa depan).
* **Hyperparameter Tracking:** Catat setiap kali Anda mengubah `learning_rate` atau `epochs`.

### Tahap 3: Sistem Penyimpanan (Persistence Layer)
Ini adalah bagian yang sebelumnya terlewat. Kita akan membuat sistem agar hasil belajar tidak hilang.

* **Model Versioning:** Simpan model dengan format: `model_v[nomor]_[tanggal].h5`.
* **Metadata Log:** Buat file `experiment_log.csv` sederhana untuk mencatat:
    * "Versi 2: Pakai fitur Mercury Retrograde & RSI. Akurasi: 55%."
* **Checkpointing:** Gunakan fitur `ModelCheckpoint` di Keras agar jika laptop Anda *crash* saat training, progresnya tetap tersimpan.

### Tahap 4: Backtesting & Evaluasi Mendalam
Jangan hanya melihat profit, lihat juga risiko.

* **Metric Evaluation:** Hitung bukan hanya akurasi, tapi juga **Precision** (seberapa sering sinyal BUY benar-benar menghasilkan profit).
* **Risk Metrics:** Tambahkan perhitungan **Maximum Drawdown** (penurunan modal terdalam) untuk melihat apakah ilmu Astronacci membantu mengurangi kerugian saat *bear market*.
* **Comparison:** Selalu bandingkan hasil strategi Anda dengan `Buy & Hold`.

### Tahap 5: Automasi & Monitoring (Cloud Integration)
Langkah terakhir untuk membawa riset Anda ke level "Production".

* **Supabase Integration:** Kirim hasil prediksi harian dari laptop ke Supabase.
* **Mobile Dashboard:** Gunakan data dari Supabase untuk memantau performa bot lewat iPhone Anda.
* **Git Versioning:** Gunakan `git` di terminal Kali Linux untuk mengelola folder `belajar-python` Anda agar kode tidak berantakan.
